# V Quiz v2

## 포함 기능
- 1~237 단어 데이터
- 객관식 퀴즈
- 반응 퀴즈: 5초 후 자동 공개 / 즉시 공개
- Chapter 1~6 범위 선택
- 직접 번호 범위 입력
- 보기 역시 선택 범위 내부에서만 생성
- 단어 번호 표시
- V Point 수정 및 브라우저 저장
- 모바일 대응

## 실행
VS Code에서 `index.html`을 Live Server로 실행하세요.
